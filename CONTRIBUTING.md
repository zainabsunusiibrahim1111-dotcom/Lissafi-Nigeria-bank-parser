# Contributing

Thank you for considering a contribution.

1. Open an issue describing the format or bug.
2. Use synthetic examples only. Never post real bank alerts or personal data.
3. Add tests for every parser change.
4. Explain uncertainty and edge cases in the pull request.
5. Do not claim a notification proves settlement or payment finality.

By submitting a contribution, you agree that it will be distributed under this repository's Apache-2.0 licence.
